Backup and Restore

Create a Backup

Download all loans and imported data as one JSON file. The backup filename automatically gets a date and time stamp.

Save location: When you click "Download Backup", your browser will now open a window where you can choose the folder (e.g. Documents \ Maluti Fruit Loan App Backups or a OneDrive folder) and the name under which the backup should be saved. If your browser does not support this feature, the file will be saved automatically to your Downloads folder.

Restore a Backup

This action replaces the data currently in the application.

Clear All Data

This permanently deletes all employees, loan types, loans, payments, payroll and Pastel data. Make a backup first if you still need the data. This action cannot be undone.
